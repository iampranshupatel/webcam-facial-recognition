# Webcam Age & Gender Detector

A sleek React + TypeScript app powered by face-api.js. Instantly estimate **age** and **gender** from your webcam or uploaded photos, all in a responsive, mobile-friendly interface.

---

## 🚀 Key Features

- **Real-Time Webcam**: Start/stop live camera detection  
- **Image Upload**: Analyze any picture in seconds  
- **Redux-Powered**: Clean state management for detections  
- **Responsive Design**: Looks great on desktop & mobile  

---

## 🛠 Tech Stack

React · TypeScript · Redux Toolkit · face-api.js · CRACO
